# Bash File System Operations & Text Processing

A POSIX-compliant Bash script designed to automate core file system manipulation, directory structure initialization, and text processing using standard Linux command-line utilities.

## 🛠 Features & Utilities Used
The script demonstrates the practical application of essential POSIX utilities:
* **Directory & File Operations:** `mkdir`, `touch`, `cp`, `mv`, `rm`
* **File Inspection & Search:** `ls`, `find`, `grep`, `cat`
* **Output & Permissions:** `echo`, `chmod`

## 🚀 Getting Started

### Prerequisites
* Any Linux distribution / macOS or WSL environment with `bash` installed.

### Execution
1. Make the script executable:
   chmod +x task.sh

2. Run the script from any working directory:
   ./task.sh

## 🧹 Behavior
The script executes without side effects: it runs cleanly, outputs the required log/summary stream to stdout, and ensures no stray temporary files are left behind upon completion.
